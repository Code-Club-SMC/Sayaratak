# Sayaratak — V2 Subset Handoff

This folder is a subset of the final v2 design handoff.

It includes all designs from `02-v2-scope-fixed` except:

- `SCR-001` through `SCR-010`
- `OVR-001` through `OVR-003`

## What this folder contains

- 108 final PNG designs
- 80 full screens (`SCR`)
- 27 overlays, drawers, dialogs, sheets, previews, and editors (`OVR`)
- 1 design system reference sheet (`DS-001`)

All PNGs in this folder come from the cleaned v2 scope-fixed set. This folder is only a filtered subset of that final handoff.

## Source of this subset

This folder was created from `02-v2-scope-fixed` by excluding the first 10 `SCR` screens and the first 3 `OVR` files.

## Screen explanations

For a plain-language explanation of every design in this subset, open [SCREEN_DESCRIPTIONS.md](./SCREEN_DESCRIPTIONS.md).

## Review guidance

- Review the PNGs in this folder only if you want the v2 subset without `SCR-001` to `SCR-010` and `OVR-001` to `OVR-003`.
- Use `SCREEN_DESCRIPTIONS.md` if you want the purpose of a screen explained in simple language.
- If you need the complete final handoff, go back to `02-v2-scope-fixed`.
